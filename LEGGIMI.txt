# Cascina Il Girasole Rosso — sito web

Sito statico responsive, pronto per essere pubblicato con GitHub Pages.

## File
- `index.html`: contenuti e struttura delle pagine
- `style.css`: grafica responsive "Giardino Incantato"
- `script.js`: menu mobile
- `images/`: fotografie ottimizzate in formato WebP

## Pubblicazione con GitHub Pages
1. Aprire il repository GitHub `cascina-il-girasole-rosso`.
2. Caricare il contenuto di questa cartella nella radice del repository (non la cartella contenitore).
3. In Settings → Pages, selezionare `Deploy from a branch`, branch `main`, folder `/ (root)` e salvare.
4. Attendere la pubblicazione automatica di GitHub Pages.

Il sito non mostra prezzi né indirizzo completo. I link di contatto puntano ai numeri WhatsApp e all'indirizzo email forniti.
